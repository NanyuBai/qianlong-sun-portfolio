# Qianlong Sun Portfolio Homepage

这是一个静态双语个人主页，用于展示景观设计作品、Studio 项目、手绘观察、简历和作品集资料。

## 文件结构

- `index.html`：页面结构和各个模块容器。
- `styles.css`：视觉样式、响应式布局、卡片和按钮样式。
- `app.js`：中英文切换、项目筛选、内容渲染逻辑。
- `data.js`：所有可编辑内容，包括中文/英文文案、项目、技能、时间线和下载文件。
- `assets/thumbs-web/`：从本地 PDF 首页生成的网页缩略图，用于项目封面和详情预览。
- `assets/photos-web/`：从 `照片` 文件夹压缩生成的网页图片，用作 Hero 主图、区块背景和内容插图。

## 后续编辑方式

常规内容更新优先修改 `data.js`。

可以继续让 Codex 执行这些任务：

- 增加一个新的项目卡片。
- 给某个 Studio 项目增加详细介绍。
- 替换首页主图。
- 调整中文或英文简介。
- 增加独立项目详情页。
- 增加真实邮箱、LinkedIn 或联系方式。
- 把 PDF 的封面页导出为项目缩略图。
- 调整项目筛选标签、Grid / Index 视图和详情弹窗内容。

## 素材使用原则

当前网站只引用本文件夹中的素材。新增素材时，建议放入清晰命名的文件夹，然后在 `data.js` 中添加路径。

所有 PDF / DOCX 文件已被纳入下载区，手绘 PNG 已用于手绘观察模块。

当前版本已把 PDF 页面导出为本地缩略图，并在项目卡片、索引视图和详情弹窗中使用。Studio 3 和 Studio 4 已接入多页案例翻阅。

`照片` 文件夹中的图片不作为照片墙集中展示，也不表述为现场调研照片；当前作为旅途风景素材选择性地用于首页主视觉、Experience 背景、Works 背景、About 背景和 Contact 背景，以透明度、遮罩和裁切控制画面层次。

## 当前页面顺序

1. Hero：姓名、身份、旅途风景主视觉和主要操作。
2. Experience：CV 摘要、工作经历时间线、教育背景、技能、课程和简历入口。
3. Works：重点作品、项目筛选、图像/索引视图和滑动案例浏览器。
4. About：设计关注和个人专业方向。
5. Observation：手绘观察和补充文档。
6. Downloads：简历、作品集和项目资料。
7. Contact：邮箱和简历入口。

## 当前交互

- Works 默认显示 Featured 项目，保留专业分类筛选。
- 案例弹窗支持左右按钮、键盘左右键、手机滑动和缩略图跳转。
- 首页本地预览地址通常为 `http://127.0.0.1:8787/`。这是本机临时预览地址，不是永久公开网址；如需永久有效链接，需要发布到正式托管服务。
